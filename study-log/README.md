# Study Log

Personal session logs for OSWE prep. **Not** exam content — your practice diary.

## Why

- Honest time tracking  
- Surface weak areas early  
- Feed `Progress-Tracker.md` and Friday reviews  

## How to use

1. Copy `SESSION-template.md` to `YYYY-MM-DD-short-topic.md`.  
2. Fill during/after the session (5 minutes).  
3. Update `weak-areas.md` if something blocked you.  
4. Weekly: skim last 7 days; pick one weak area to attack.

## Naming

```text
2026-07-11-atutor-type-juggling.md
2026-07-12-blind-sqli-drill.md
2026-07-13-challenge-lab-01.md
```

## Privacy

Do not commit real exam flags, proctor details, or non-public credentials. This folder can stay local (add to `.gitignore` if you prefer).
